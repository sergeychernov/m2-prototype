# CircuitPython на RP2040-Zero

Ниже краткая инструкция по развёртыванию и запуску примера `code.py` на плате RP2040-Zero.

## Подготовка платы
1. Скачайте свежую версию CircuitPython для Raspberry Pi Pico с [официальной страницы загрузки](https://circuitpython.org/board/raspberry_pi_pico/). Для RP2040-Zero подходит именно этот билд.
2. Зажмите кнопку **BOOTSEL** на плате и подключите её к компьютеру по USB. Появится съёмный диск `RPI-RP2`.
3. Скопируйте загруженный `.uf2` файл CircuitPython на диск `RPI-RP2`. После перезапуска появится диск `CIRCUITPY`.

## Загрузка примера
1. Откройте появившийся диск `CIRCUITPY`.
2. Скопируйте файл [`code.py`](./code.py) в корень `CIRCUITPY` (замените существующий, если он был).
3. Плата автоматически перезапустится и начнёт выполнять скрипт: встроенный LED будет мигать, а в консоль REPL каждые несколько секунд выводится статус.

## Просмотр вывода
- Для подключения к REPL используйте любой серийный терминал (например, `screen` или `picocom`) на скорости **115200** бод.
- Чтобы остановить выполнение, подключитесь к REPL и нажмите **Ctrl+C**.
